<objective>
Rule 42 makes learning curves a mandatory README section — a graded deliverable, not
diagnostics. The trap is timing: curves that are added "once training works" require re-running
the overnight job to produce them, and the run is the expensive part. So instrumentation ships
with the first episode of the first run.

The second trap is resume. `03-RESEARCH.md` §3 flags it: a resumed run that keeps appending
produces a CSV with a duplicated, rewound segment, and the PNG rendered from it shows a
learning curve that never happened. Truncate-on-resume is the fix.

Output: `training/curves.py`, `training/plot_curves.py`, and the README section.
</objective>
