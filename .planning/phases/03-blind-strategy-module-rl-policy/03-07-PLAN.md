<objective>
STRAT-05: the cop selects barrier placement via `_decide_move`. This is the second stage of the
two-stage decision locked by D-12 — the Q-policy chooses movement over 5 actions, then this
module decides whether and where to place a barrier. Keeping placement out of the action space
is what stops the learner's action dimension from multiplying by every board cell.

Two rules make this higher-stakes than it looks. The barrier quota is a hard game parameter, and
rules 16/22 make a *misdeclared* barrier a disqualification — so "the barrier we announce is the
barrier we place" has to be a tested property, not a comment.

Output: `src/pursuit/strategy/barriers.py`, wired into both brains' cop-side `_decide_move`.
</objective>

  <action>
    Tests first. Then `barriers.py` exposing:

      choose_barrier(state, params, believed_thief_cell) -> tuple[int,int] | None

    Selection: score each legal candidate cell by how much placing it **increases the thief's
    BFS distance to its best escape** (equivalently, shrinks its reachable region), and take the
    best-scoring candidate above a configured improvement threshold. Return `None` when no
    candidate clears the threshold — spending a barrier for no gain is strictly worse than
    keeping it, since the quota is finite.

    Hard constraints:
    - Return `None` immediately when `state.barriers_placed >= params.barrier_quota`.
    - Only ever return a cell the engine would accept; validate against the engine's own
      legality check rather than reimplementing it (QUAL-02).
    - Never return the thief's or the cop's current cell.
    - Pure function: no counters, no caches, no module-level state (D-03).

    Keep candidate evaluation bounded — the search is over board cells with one BFS each, on a
    7×7 board. If profiling shows it near the `max_decision_ms` budget, restrict candidates to
    cells adjacent to the thief's shortest path rather than caching across turns.
  </action>
  <verify>
    `uv run pytest tests/unit/strategy/test_barriers.py -q` passes, covering: a placement that
    lengthens the thief's escape is chosen; no candidate above threshold returns None; quota
    exhausted returns None; the returned cell is always engine-legal; never returns an occupied
    cell; identical inputs give identical output.
  </verify>
</task>
