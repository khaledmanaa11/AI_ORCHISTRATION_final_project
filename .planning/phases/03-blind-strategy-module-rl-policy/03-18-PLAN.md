<objective>
The mover. Under D-26 alpha-beta replaces the Q-policy as what actually picks the move, searching
over the linear evaluation 03-16 learned.

**Why alpha-beta and not MCTS:** MCTS misses shallow traps (Ramanujan et al., ICAPS 2010), and
barrier sealing is precisely a shallow trap — a sealing move looks unremarkable until the ply where
the component closes. A trap closing in k thief moves needs depth ≥ 2k plies to be visible.

**Why this is the phase's performance risk:** search cost is the one thing that can make the agent
miss its move deadline in a league game. The budget contract below — always return the best move
from the last *completed* iteration, never raise — is what makes a slow search a weaker move rather
than a forfeited one.

Output: `search.py`, and `transposition.py` if the split triggers.
</objective>

    Tests first. `search.py` (~60-140 code lines):

      search(state, params, game_params, weights, successors, *, deadline_ms, depth_cap) -> Decision

    Iterative deepening from depth 1 upward. After each **completed** depth, record its best move.
    On budget expiry or `depth_cap`, return the last completed depth's move.

    Non-negotiable behaviours:

    1. **Never raise, never return None.** A depth-1 search always completes (the move set is at
       most 5 for the thief), so a best move always exists. If the budget expires mid-iteration,
       **discard that iteration entirely** — a partial depth has searched some siblings and not
       others, so its argmax is biased toward whatever was ordered first.
    2. **Deterministic.** Move ordering: TT best move first, then fixed `sorted()` cell order.
       Ties resolve on that same order. The TT changes speed, never the returned move — assert this
       by running with the table disabled and comparing.
    3. **Terminal leaves use 03-16's ±INF sentinel**, never `w·phi`. Absorbing, and pruned.
    4. **`successors` is injected**, not imported. The cop's expansion (move × 03-17's pruned
       barrier candidates) and the thief's (03-12's safety-filtered moves) both belong to 03-19.
       This keeps the algorithm testable against a toy successor function.
    5. Free-cell derivation is hoisted to once per node (03-11's contract), not recomputed per
       feature.
