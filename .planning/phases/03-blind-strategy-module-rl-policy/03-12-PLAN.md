      closed_neighbourhood(state, params) -> frozenset[Coord]   # N[cop]
      safe_moves(candidates, state, params) -> list[Coord]

    Contract:
    - `safe_moves` returns the members of `candidates` **not** in `N[cop]`, preserving the caller's
      ordering so an already-sorted input stays deterministic.
    - **When that would be empty, return `candidates` unchanged.** Never an empty list — a thief
      with no candidate set is a crash, not a strategy.
    - Pure: no module-level mutable state, no caches, no role object, no I/O (D-03). Candidates come
      from the caller, so the module never asks who is moving and no cop path can reach it.

    The module docstring carries in full the 296/300 = 0.987 vs 283/300 = 0.943 provenance (random
    starts, no training, real engine) **and** the D-31 caveat exactly as the objective states it.
    Do not soften it and do not drop it for length.
