<objective>
The measurement layer for run 2. Barriers keep the board triangle-free, so **cop-win is
equivalent to the thief's free component being a forest** — the cop destroys cycles, the thief
preserves one. Distance is the wrong objective for both roles (`<superseded>` overturning D-09);
this package supplies the quantities that replace it.

Nothing here decides a move. It is a pure library that 03-16 (features), 03-17 (barrier
objective) and 03-18 (alpha-beta search) are all built on, and it lands first and alone so those
three can be written against a fixed API.

Output: new package `src/pursuit/strategy/graph/` — three algorithm modules, tests mirroring
one-to-one under `tests/unit/strategy/graph/`.
</objective>

  <action>
    Tests first. Then `components.py`, the base module the other two import:

      free_cells(state, params) -> frozenset[Coord]      # in-bounds minus state.barriers
      neighbors(cells, cell) -> frozenset[Coord]         # THE one adjacency implementation
      component_of(cells, start) -> frozenset[Coord]
      degree(cells, cell) -> int
      edge_count(cells) -> int
      articulation_points(cells) -> frozenset[Coord]

    Contracts:
    - `free_cells` is the **only** function taking `(GameState, GameParams)`; everything else
      takes the derived set, so 03-18 derives once per search node (D-26). Agents' own cells are
      free cells — they are not barriers. Callers subtract what they want excluded and the
      library never learns why (D-03).
    - `neighbors` excludes `Direction.STAY`. A self-loop would corrupt `degree` and
      `edge_count`, and through them cycle rank.
    - `edge_count` counts each undirected edge once.
    - `articulation_points` is Hopcroft–Tarjan with an **explicit stack**; recursion is banned.
      Root is a cut vertex iff it has ≥2 DFS children. Handles a disconnected input set.
    - Out-of-set cells: `component_of` → empty frozenset, `degree` → 0. Never raise — the cop
      can legally wall a cell off, so this is an ordinary state (`pathfind.UNREACHABLE`'s logic).

    QUAL-02, settled here so it is not re-litigated downstream: `pathfind.bfs` reaches adjacency
    through `get_legal_moves`, which builds a probe `GameState` per cell — fine for one distance
    query, far too heavy inside alpha-beta. So this package keeps **one copy, in this module**,
    of set-membership adjacency, pinned equal to the engine's by the test below: a justified
    second implementation with a proof, not a silent duplicate.

    `__init__.py` re-exports the public names (fill in as Tasks 2–3 land).
  </action>

      territory_diff(cells, first, second) -> tuple[int, int]   # (cell_diff, edge_diff)

    Contracts:
    - One simultaneous two-source BFS, not two separate runs — a cell belongs to whichever
      source reaches it strictly sooner.
    - **Equidistant cells belong to neither side.** The grid is bipartite, so ties are common
      rather than exotic; dropping them keeps the split deterministic with no tie-break rule and
      makes `first | second` a strict subset of the reachable cells. Put this invariant in the
      docstring — a caller assuming a partition would be wrong.
    - Cells unreachable from both sources belong to neither.
    - `territory_diff` returns `(len(first) - len(second), edge_count(first) - edge_count(second))`
      via `components.edge_count` — no second edge counter (QUAL-02).
    - Arguments are positional and symmetric; the library never names a side (D-03). Callers
      pass their own cell first and read a positive difference as their advantage.
