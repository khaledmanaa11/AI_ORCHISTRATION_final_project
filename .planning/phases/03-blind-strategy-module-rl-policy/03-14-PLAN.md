<objective>
R2 and R4 — the two correctness defects that left the thief's MDP degenerate.

**R2, measured:** `harness.py::_turn` calls `_update_learner` only when `role == learner.role`, and
capture is produced by `engine.apply_cop_action` on the **cop's** turn — so a thief learner is never
told it was caught. Instrumented: a thief walked into the cop, captured **300/300**, received
**exactly one update per episode worth −0.01** (the ordinary step cost). `_reward` returns
`reward_capture if role == "cop" else 0.0`. The single most important event in the thief's world
produces no signal at all. The defect is **symmetric** — SURVIVAL is emitted only by
`engine.apply_thief_move`, so a cop learner is equally blind to survival.

**R4:** `QLearningBrain.update` always computes `reward + gamma * max_a Q(next_key, a)`. At episode
end `next_key` is an ordinary encoded key colliding with non-terminal states that share the same
positions, mask, `barriers_used` and bucket, so terminal values leak into live states.

Output: `training/rewards.py` (new), a terminal-aware `_turn`, and `update(..., terminal=...)`.
</objective>
