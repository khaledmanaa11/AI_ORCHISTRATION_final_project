<objective>
Lay the Phase-2 foundation so all five later waves can start on day one without
rediscovering structure: install the FastMCP dependency, enable async testing, create the
per-agent network config that every resilience number in this phase is read from, register
its field names as structural constants, and drop a named test stub for every module the
phase will build.

No network behaviour is written here. No FastMCP server is constructed, no tool is
declared, no state machine exists yet. This plan produces configuration, constants, an
empty package root, and skipped test stubs — nothing more.

Purpose: Wave 1 (02-01 loader, 02-02 envelope+digest, 02-03 state machine, 02-04
event-log+watchdog) and Waves 2-5 all depend on this plan for (a) an installed, locked
`fastmcp`, (b) `pytest-asyncio` with `asyncio_mode = "auto"` so async tests need no
decorator, (c) `config/{police,thief}/network.json` as the single source of every network
number, (d) `NetworkConfigKey` so no loader has to spell field names as bare strings, and
(e) an importable, already-named stub file per module so the stub-then-fill pattern never
causes an intra-wave file collision.

`uv run ruff check .` exits 0; `bash scripts/check_line_limit.sh` passes; `from fastmcp
import Client, FastMCP` works; and every Phase-2 number sits in config, never in source.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| filesystem → config loader | `network.json` is a new trust root: it supplies the listen port, the opponent URL, and every resilience deadline. A malformed or tampered file must fail loud at load (loader written in 02-01, not here) |
| environment → process | D-16 makes host/port/opponent_url env-overridable, so the process environment becomes an input channel that can redirect where an agent listens and who it calls |
| developer → repo | `.env-example` is committed; it must never gain a real value (QUAL-12) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-00-SC | Tampering | `uv add fastmcp`, `uv add --dev pytest-asyncio` | mitigate | `fastmcp` is the protocol library CLAUDE.md mandates; RESEARCH.md verified the package identity against PyPI's JSON API **and** the `v3.4.5` git tag source on `PrefectHQ/fastmcp` (confirming `jlowin/fastmcp` now redirects there), not against a blog post. `pytest-asyncio` is the pytest org's own async plugin. | T-02-00-01 | Tampering | `config/{police,thief}/network.json` | mitigate | New trust root. | T-02-00-02 | Tampering | `config/{police,thief}/game_params.json` | mitigate | The real risk this plan guards against: putting per-side endpoints in `game_params.json` would break its byte-for-byte identity and hand a free NET-09 abort — or, worse, mask a genuine mismatch.
