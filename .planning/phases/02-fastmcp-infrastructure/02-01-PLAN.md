building a second JSON loader would otherwise create.

Two halves, one plan, because they touch the same code:

1. **Extract (QUAL-02).** `src/pursuit/shared/config.py` already contains `_require_key` and
   `_require_int` — a private, fail-loud validation pair with the filename `game_params.json`
   baked into its error messages. A second loader would be the second copy. Per Table 5
   ("extract at 2+ copies"), move that pair into `src/pursuit/shared/loader_helpers.py`,
   parameterised by the source filename, and re-point `config.py` at it. Do not copy-paste a
   second validator.
2. **Load (NET-01, NET-02).** Add `src/pursuit/shared/network_config.py` with a frozen
   `NetworkParams` dataclass and `load_network_config(path) -> NetworkParams`, built on the
   extracted helpers, reading the per-agent `config/{police,thief}/network.json` files that
   02-00 created (D-04). Every missing or mistyped key fails at load time. Host, port and
   opponent URL are overridable from the environment per D-16.

Purpose: `network.json` is the trust root for every endpoint and every resilience deadline in
Phase 2 — 02-06's `PeerRuntime`, 02-07's deadline tracker and 02-09's orchestrator all read
their numbers through `NetworkParams` and never from source (QUAL-11). Fail-loud means a
malformed endpoint is caught at startup, not three moves into a league game. Returning a fresh
value object per call — never a module-level singleton — is what keeps the cop and thief
processes from ever sharing a live config object (NET-02, project rule 2).

      def require_key(data: dict, key: str, *, source: str) -> object:
          if key not in data:
              raise KeyError(f"Required key '{key}' missing from {source}")
          return data[key]

      def require_int(data: dict, key: str, *, source: str) -> int:
          value = require_key(data, key, source=source)
          if not isinstance(value, int):
              raise TypeError(
                  f"{source} field '{key}' must be int, got {type(value).__name__!r}"
              )
          return value

      def require_str(data: dict, key: str, *, source: str) -> str:
          value = require_key(data, key, source=source)
          if not isinstance(value, str):
              raise TypeError(
                  f"{source} field '{key}' must be str, got {type(value).__name__!r}"
              )
          return value
