<objective>
Build the two resilience primitives that make D-14's "persist-every-turn" strategy real: the
JSONL event log (the durable sink) and the watchdog daemon thread (the freeze detector that
writes before it dies).

Purpose: D-11 locks a structured JSONL event log per agent plus a human-readable console echo.
That log is three things at once — the NET-05 sink into which 02-03's `transition(..., reporter)`
reports every illegal transition, the NET-07 "rescues data" guarantee (a crash mid-game loses
nothing because every turn is already fsynced), and the seed of the Phase-7 `log_<game_id>`
artifact and replay viewer. Because Phase 7 will read these files back, the schema has to be
small, stable and forward-compatible **now**; reshaping it later means rewriting the replay
viewer's parser.

The watchdog is the other half of D-14: a background daemon thread watching a last-activity
timestamp against the 60 s threshold (PARAMETERS.md Table 19 row 7), which on freeze writes a
final incident record and exits cleanly. RESEARCH Pitfall 6 names the exact way this fails —
`os._exit()` terminates instantly with no cleanup, so a buffered-but-unflushed incident record
never reaches disk and NET-07's whole purpose is defeated. Hence two hard design rules here:
the write is flushed **and** fsynced *before* the exit fires, and the exit itself is an
**injected callable**, so the test suite can assert that ordering without killing the pytest
process.

Two modules rather than one because of the 150-line limit, and because they must stay mutually
independent: `event_log.py` never imports `watchdog.py` and vice versa. Wiring them together is
02-09's job. That independence is also what lets this plan run in parallel with 02-01/02-02/
02-03/02-05 in Wave 1.

Output:
- src/pursuit/network/event_log.py — EventType / EventField / build_event / append_event / console_line
- src/pursuit/network/watchdog.py — Watchdog (daemon thread, injected clock + sleeper + exit)
- tests/unit/test_event_log.py — durability and fail-loud rejection tests
- tests/unit/test_watchdog.py — quiet-path, freeze-ordering and lifecycle tests
</objective>
