<objective>
Build the per-agent turn state machine: a `State` enum, an explicit `ALLOWED_TRANSITIONS`
table, a `TransitionSeverity` classification, and a `transition(current, target, *, reporter)`
function that **reports every illegal attempt** — using RED -> GREEN -> REFACTOR TDD cycles.

Purpose: NET-04 requires the orchestrator to drive turn order through a proper state machine;
NET-05 (rule 5, `docs/RULES.md`) requires **every** attempt to transition to an illegal state to
be reported — a silent rejection is the disqualifying failure mode, not the rejection itself.
D-10 makes the response severity-based: a duplicate message or an out-of-order retry is
RECOVERABLE (log, reject, keep playing), while a real protocol violation escalates to
`State.ERROR` and ends the game. The return value must tell the caller which of those two
happened, so the orchestrator (02-09) never has to guess.

The reporter is **injected as a parameter**, not imported. That is a deliberate architectural
choice, not a style preference: it keeps `state_machine.py` free of any dependency on
02-04's `network/event_log.py`, which is what allows 02-03 and 02-04 to execute in the same
wave — and it makes NET-05's "was it reported?" assertion trivial with a fake reporter instead
of filesystem inspection.

This module is an enum plus two constant tables. It must contain **zero numeric literals**
(CLAUDE.md rule 1: never invent a number). If a number appears necessary, stop and record it
under `## OPEN` rather than choosing one.

class State(Enum):
    """The six D-09 states. Phase 6 inserts commit-reveal sub-states additively."""
    INIT          = "init"
    HANDSHAKE     = "handshake"
    MY_TURN       = "my_turn"
    WAIT_OPPONENT = "wait_opponent"
    GAME_OVER     = "game_over"
    ERROR         = "error"

ALLOWED_TRANSITIONS: dict[State, frozenset[State]]
    # Explicit table (D-12). Every State member is a key — no KeyError is reachable.
    # INIT          -> {HANDSHAKE, ERROR}
    # HANDSHAKE     -> {MY_TURN, WAIT_OPPONENT, ERROR}
    # MY_TURN       -> {WAIT_OPPONENT, GAME_OVER, ERROR}
    # WAIT_OPPONENT -> {MY_TURN, GAME_OVER, ERROR}
    # GAME_OVER     -> frozenset()   (terminal)
    # ERROR         -> frozenset()   (terminal)

TERMINAL_STATES: frozenset[State]   # {GAME_OVER, ERROR}

class TransitionSeverity(Enum):
    RECOVERABLE        = "recoverable"          # duplicate / out-of-order retry — game continues
    PROTOCOL_VIOLATION = "protocol_violation"   # escalates to ERROR — game ends

RECOVERABLE_ATTEMPTS: frozenset[tuple[State, State]]
    # Explicit allow-list of *illegal but benign* (current, target) pairs (D-10).
    # Everything illegal and not in this set is a PROTOCOL_VIOLATION.

class TransitionReporter(Protocol):
    """Injected reporting sink. 02-04's event_log adapts to this shape; 02-09 wires them."""
    def __call__(
        self,
        *,
        current: State,
        target: State,
        severity: TransitionSeverity,
        reason: str,
    ) -> None: ...

@dataclass(frozen=True)
class TransitionResult:
    state: State                          # the state the machine is in AFTER the attempt
    accepted: bool                        # True only when the requested transition applied
    severity: TransitionSeverity | None   # None when accepted; set on every rejection

    @property
    def continues(self) -> bool:
        """True when the caller may keep playing (state is not terminal)."""

def classify_severity(current: State, target: State) -> TransitionSeverity: ...
    # Table lookup only: RECOVERABLE if (current, target) in RECOVERABLE_ATTEMPTS,
    # else PROTOCOL_VIOLATION. Never called for a legal transition.

def transition(current: State, target: State, *, reporter: TransitionReporter) -> TransitionResult:
    """NET-05: every illegal attempt is reported. Legal -> apply. Illegal -> report, then
    reject (RECOVERABLE, state unchanged) or escalate to State.ERROR (PROTOCOL_VIOLATION)."""

class TurnStateMachine:
    """Per-agent instance. Holds THIS agent's state only (NET-02) — no module-level
    mutable current-state variable, so two machines never share runtime state."""
    def __init__(self, reporter: TransitionReporter, *, initial: State = State.INIT) -> None: ...
    @property
    def state(self) -> State: ...
    def attempt(self, target: State) -> TransitionResult: ...

<design_notes>
<!-- Decisions made inside this plan's delegated discretion. State them in the SUMMARY. -->

1. **ERROR is reachable from every non-terminal state.** RESEARCH Pattern 7 sketches
   `INIT -> {HANDSHAKE}`; this plan adds `ERROR` to INIT's set as well. Rationale: D-10's
   escalation must itself be a *legal* transition looked up in the table, not a special case
   that bypasses it. Terminal states stay empty — nothing escapes GAME_OVER or ERROR.

2. **Severity is classified by the module, not passed in by the caller.** The signature is
   fixed at `transition(current, target, *, reporter)` by the manifest. Classification is a
   second explicit table (`RECOVERABLE_ATTEMPTS`), consistent with D-12's "explicit table, not
   a library" spirit, and equally unit-testable.

3. **Which illegal attempts are RECOVERABLE (D-10's "duplicate message, out-of-order retry"):**
   - self-transitions — the peer re-delivered a message we already applied:
     `(HANDSHAKE, HANDSHAKE)`, `(MY_TURN, MY_TURN)`, `(WAIT_OPPONENT, WAIT_OPPONENT)`,
     `(GAME_OVER, GAME_OVER)`
   - a late/duplicate handshake arriving after we advanced:
     `(MY_TURN, HANDSHAKE)`, `(WAIT_OPPONENT, HANDSHAKE)`
   Everything else illegal is a PROTOCOL_VIOLATION — including anything attempted out of
   `ERROR`, and any attempt to jump backwards to `INIT`.

4. **Rejection is never silent, and neither is escalation.** `reporter` is called on *every*
   illegal attempt, before the return value is computed — including the PROTOCOL_VIOLATION
   path. A legal transition calls the reporter zero times (state-transition logging of *legal*
   moves is 02-09's job via the event log, not this module's).

5. **Phase 6 additivity.** Adding commit-reveal sub-states later must mean: new `State` members
   plus new rows/edges in `ALLOWED_TRANSITIONS`. No signature of `transition()` may need to
   change. Do not add those states now.
</design_notes>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| opponent message -> orchestrator -> `transition()` | The `target` argument is ultimately derived from a message the *opponent* sent. It is untrusted input: any State value, in any order, at any time. `transition()` must treat every (current, target) pair as adversarial and decide purely from the tables — never from an assumption about what the opponent "would" send. |
| caller -> `reporter` | The reporter is injected by the caller (02-09 wires the event log). This module must not assume the reporter succeeds, but must also not swallow its own reporting duty behind a try/except that could silently drop a NET-05 report. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | `ALLOWED_TRANSITIONS` / `RECOVERABLE_ATTEMPTS` | mitigate | Both tables are module-level `frozenset` values inside a `dict` of frozensets; a caller cannot `.add()` an edge at runtime to legitimise an illegal move. `TransitionResult` is a frozen dataclass, so a result cannot be rewritten after the fact. |
| T-02-03-02 | Tampering | Opponent forces an out-of-order state jump | mitigate | Legality is table-driven only. An opponent replaying an old message reaches at worst a RECOVERABLE rejection (state unchanged); anything else is a PROTOCOL_VIOLATION that lands the machine in terminal ERROR, which has no outgoing edges — the game cannot be dragged onward from a violated state. |
| T-02-03-03 | Repudiation | An illegal attempt goes unreported (rule 5 sanction) | mitigate | The reporter is called on a **single** code path before the outcome branch, so no return path can skip it; `test_illegal_transition_is_rejected_and_reported` asserts exactly one call with current/target/severity/reason, and the RECOVERABLE and PROTOCOL_VIOLATION tests each assert their own report. Reporting is the tested contract, not a side effect. |
| T-02-03-04 | Information Disclosure | Leaking own state to the opponent (rule 2 / NET-02) | mitigate | This module holds no board data, no move, no position — only a six-value enum. `TurnStateMachine` keeps that value on the instance, so a cop process and a thief process can never observe one another's state even if both are imported into one interpreter (asserted by `test_machines_do_not_share_state`). |
| T-02-03-05 | Denial of Service | Escalation loop / livelock on repeated illegal attempts | accept | Terminal states have empty transition sets, so repeated attempts after ERROR are cheap, pure, and always rejected; there is no retry, no sleep and no I/O in this module. Bounding *time* is 02-07's deadline tracker, not this module's job. |
| T-02-03-SC | Tampering | Supply chain | mitigate | This plan adds **zero** dependencies — D-12 forbids an FSM library and the module imports stdlib only (`dataclasses`, `enum`, `typing`). Task 3 greps `pyproject.toml` to prove no such package was introduced. |

No HIGH-severity threats: the module is a pure, side-effect-free decision function over two
immutable tables, with no network access, no file I/O, no secrets, and no numbers. Its single
security-relevant obligation is that **no illegal attempt escapes unreported** (rule 5), and
that obligation is pinned by a named test rather than by inspection.
</threat_model>
