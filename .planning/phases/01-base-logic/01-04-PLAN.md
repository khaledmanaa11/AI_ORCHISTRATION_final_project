    apply_cop_action(
        state: GameState,
        move_to: tuple[int, int] | None,
        barrier_at: tuple[int, int] | None,
        params: GameParams,
    ) -> tuple[GameState, "Outcome | None"]
      Step 1: if move_to is not None, apply_move(state, "cop", move_to) -> after_move
               else after_move = state
      Step 2: if barrier_at is not None, place_barrier(after_move, barrier_at, params) -> after_barrier
               else after_barrier = after_move
      Step 3: detect_capture(after_barrier, params) -> outcome
      Returns (after_barrier, outcome)
      This is wiring only — no business logic; each step delegates to its owning module.
