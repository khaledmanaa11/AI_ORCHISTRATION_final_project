    board.py — two public pure functions:

    get_legal_moves(state: GameState, agent: str, params: GameParams) -> list[tuple[int, int]]:
    - Determine current position: pos = state.cop if agent == "cop" else state.thief.
    - Candidates = stay (pos itself) plus the four orthogonal steps using Direction deltas.
    - Filter: keep candidate c if 0 <= c[0] < params.board_size AND
              0 <= c[1] < params.board_size AND c not in state.barriers.
    - Stay (pos) passes the barrier check always (D-13: the thief's own cell cannot be a
      barrier because barrier-on-thief = capture; this is enforced upstream by barrier.py
      in plan 01-02. board.py assumes a valid state where stay is always safe).
    - Return the filtered list. Order does not matter for correctness.
    - No hardcoded board size — always use params.board_size.

    apply_move(state: GameState, agent: str, dest: tuple[int, int]) -> GameState:
    - Use dataclasses.replace(state, cop=dest) if agent == "cop",
      dataclasses.replace(state, thief=dest) if agent == "thief".
    - Return the new frozen GameState. Do not modify the original.
    - This function does NOT increment the turn counter — turn management belongs in the
      orchestrator (plan 01-03 / Phase 2). It only repositions the agent.
