  <action>
    `Gatekeeper.submit(fn, *, estimated_tokens)` — async, provider-agnostic, and the only door to
    an external service. In order: consult the budget's degrade level; acquire the parallel-call
    semaphore; await the token bucket; run `fn` under the configured response timeout; on a
    retryable failure back off by the configured wait-after-error for the configured retry count;
    settle the budget with the observed usage.

    **Overflow is a queue, not a crash** (QUAL-05). Admission beyond the parallel cap enqueues
    FIFO up to the configured queue depth. Only when the queue itself is full does `submit`
    raise `GatekeeperOverflow` — a typed exception whose entire purpose is to be caught by the
    caller and turned into the deterministic fallback of D-33. Document that contract in the
    docstring so plan 04-07 and 04-10 do not invent their own handling.

    Nothing here imports `anthropic`. `fn` is supplied by plan 04-06.

    If this file approaches 150 lines, split the queue/semaphore machinery into a sibling module
    rather than compressing — the standing rule is split, never compress.
  </action>
