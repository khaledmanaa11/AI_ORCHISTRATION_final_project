Put a language model behind one interface, one door, and one failure type.

API tokens (§6.5.1). Ours is `claude_api` with Haiku 4.5, and `template` is what we fall back to
when the key is missing, the budget is spent, or the API misbehaves — which, in a league game,
must never be visible as anything worse than a duller hint.

    A `Provider` protocol with a single async method: given a system prompt, a user prompt and an
    optional JSON schema, return `LlmResult` (text, parsed object when a schema was supplied, and
    observed usage) or `LlmFailure` (a reason enum plus a message).

    **`LlmFailure` is a return value, not an exception.** That is the whole of D-33 in one design
    choice: the turn loop cannot be taken down by something it is not obliged to inspect. Reasons
    to enumerate: no key, auth, rate limited, timeout, connection, bad request, schema invalid,
    overflow, budget exhausted, disabled.

    `template_provider.py` satisfies the same protocol with zero tokens and no network. It is the
    book's default mode and our floor; the actual sentence bank is 04-10's, so this provider takes
    its phrases as an injected sequence and does the selection only.

    The registry is an explicit dict, `{"template": ..., "claude_api": ...}`, keyed by the config
    string. `ollama` and `claude_cli` appear **only** in a docstring naming them as §6.5.1
    extension points — no stub class that raises, because a stub in a registry is a live footgun.
    An unknown provider name is a load-time `ValueError`, not a runtime surprise.
  </action>
  <verify>
    The template provider satisfies the protocol and returns a result with zero usage. An unknown
    provider name raises at load. `LlmFailure` is never raised anywhere in the package

    environment; if it is absent, the provider is simply unavailable and every call returns
    `LlmFailure(NO_KEY)`. Set the SDK's `timeout` from config and its `max_retries` to **0** — the
    gatekeeper owns retries (D-34), and two retry layers would multiply the backoff and blow the
    watchdog deadline.

    `anthropic_provider.py`:
    - builds the request — model id from config, small `max_tokens` from config, a system prompt,
      one user message, and `output_config={"format": {"type": "json_schema", "schema": …}}` when
      the caller supplies a schema;
    - estimates tokens with `count_tokens` where the call is worth it and hands the request to
      `Gatekeeper.submit` as a callable. **It does not call the SDK directly** (QUAL-03);
    - reconciles the budget with `response.usage`, not the estimate;
    - maps **every** SDK error class and `GatekeeperOverflow` onto an `LlmFailure` reason. A bare
      `except Exception` is acceptable only as a final arm that also logs the class name — an
      unmapped error must degrade, not escape.

    `.env-example` gains `ANTHROPIC_API_KEY=your-key-here`. Confirm `.env` is gitignored.
  </action>
