# 05-12 — a malformed peer cannot kill us at the handshake

**Gap (verify-work Round 2, 2026-08-16, HEAD `bcc04bf`).** Two blocker-class holes, both
reachable by the opponent alone, both ending in a process death **before move 1** — which
makes US the side that published no nonces under rule 36, the exact artifact class that
05-04, 05-09 and 05-10 exist to prevent.

**G9 — reproduced by direct probe against live source.** `config_hash.digests_match`
raises `TypeError` on any non-str argument (`:57-58`). Both handshake call sites pass
peer-controlled values unchecked and both sit **outside** the `try/except` at
`handshake_evaluate.py:151-156`, which wraps the DECODE block only — reading
`envelope.payload[HandshakeKey.DIGEST]` at `:155` is a plain dict lookup that succeeds for
an int. `:118` (config) is unconditional; `:124-125` (scent) is live because
`agent_entrypoint.py:80,85` always supplies `local_scent_digest`. `handshake.py` calls
`evaluate()` bare on both halves, and `:96` documents `respond_to_handshake` as "Pure,
synchronous, never raises" — the probe disproves it. A green test,
`tests/unit/test_config_hash.py:131-135`, currently certifies the crash as intended.

**G7 — introduced by the D-61 game-id fix.** `adopt_negotiated_game_id` hands
`result.peer_game_id`, read verbatim at `handshake_evaluate.py:162` with no type check
(`Envelope.from_dict` validates the payload only as a dict), into three unsafe sinks: a set
constructor (`:157-158`, unhashable -> TypeError), a filesystem path (`:162-164`, traversal
+ silent overwrite via `Path.replace`), and the audit's membership key (a falsy `''`
excludes the peer's real id and false-accuses an honest opponent).

**Fix shape (three tasks).**

1. `config_hash.py` — `compare_named_digest` treats a non-str `remote` as a named
   non-agreement, the same shape as its existing `remote is None` branch, so the detail
   string distinguishes "absent" / "wrong type" / "differed". `digests_match` is untouched:
   its strict contract still guards internal misuse. Re-specify
   `test_config_hash.py:131-135` to assert the named mismatch through the caller, and keep
   a direct `pytest.raises(TypeError)` test on `digests_match` itself so the strict contract
   stays pinned. Record the before/after probe verbatim in the SUMMARY.
2. `game_identity.py` (135/150 at HEAD — **measure after this task and split into the
   pre-authorized `game_identity_validate.py` if over; never compress to fit**) — one
   `_usable_peer_game_id(value)` gate applied BEFORE any use:
   returns the value only when it is a non-empty `str`, free of path separators and `..`,
   and within a bounded source constant; otherwise the peer counts as having published no
   id. Make `:71` and `:157-158` consume that single answer so "absent" cannot mean two
   different things. Filenames derive from a sanitised value (or keep our own uid and hold
   the negotiated id as data only) — no peer string reaches a `Path`. Leave the audit's
   membership leniency exactly as D-61 specified.
3. Tests + the rule comment — an adversarial peer-id suite (unhashable, traversal, empty,
   over-long, non-str) each ending in a named outcome and never a traceback, **plus the
   control that matters most: an honest peer using a foreign id convention is still
   MATCHED**, and `test_game_id_negotiation.py` still passes with the two sides given
   deliberately different uids. Extend `audit.py:56-90` with instances 7 and 8 and the
   handshake corridor, so the "next one is a review failure" claim stays true.

**Line budget** (measured at HEAD `bcc04bf`; `scripts/check_line_limit.sh` is the
authoritative counter and currently exits 0 for the whole tree — re-run it before every
commit rather than trusting these figures): `config_hash.py` 65, `game_identity.py` **135**,
`audit.py` **142**, `audit_shape.py` 73, `audit_record.py` 26. Only `game_identity.py` is
tight, which is why its split is pre-authorized above. `audit.py` has room for the
boundary-rule comment extension in task 3, but if the count moves, that comment goes to
`audit_shape.py` with a one-line pointer rather than compressing anything.

**Non-goals.** No change to the audit's membership-vs-equality choice (D-61, deliberate).
No new config field or tunable (rule 1). No rewrite of `Envelope.from_dict` into a schema
validator — this plan contains the two live sinks, it does not re-architect envelope
parsing. No touching the 403/secret path (`test_secret_channel.py` must pass unedited).
