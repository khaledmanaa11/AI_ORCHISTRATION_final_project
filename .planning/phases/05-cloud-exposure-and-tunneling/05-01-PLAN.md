    clock)` — every pyngrok call and every timing primitive injected, real defaults bound in

    `start()` connects the configured local port to the static domain and stores
    `public_url`; raises loudly on failure (auth, domain taken, no network). `healthy()`

    unhealthy, bounded by `network_params.retry_count` with `backoff_seconds` waits (injected
    sleep). `stop()` disconnects then kills, idempotent.

    a watchdog freeze — the runtime keeps playing; only ingress is broken.
  </action>

    healthy=False sequence triggers exactly retry_count reconnect attempts with backoff
    sleeps recorded; reconnect uses the same domain; stop calls disconnect then kill once

  </verify>
