# 05-11 — a dropped tunnel is repaired mid-game, not played dead

**Gap (attempt 2, 2026-08-16, game `5efbc5811fabfac4`).** A→B still delivered at
09:35:01Z; B's pushes to A then raised `ConnectError` (4-attempt ladder, verdict at
09:35:16.9Z); A was alive until its watchdog killed it at 09:36:02Z. Machine A's public
ingress (its ngrok tunnel) died mid-game and nothing in `src/` could repair it:
`ensure_connected()` — designed, tested, documented for exactly this under D-55 — had
**no production caller**. Evidence: `docs/phases/phase-5/remote-round-2026-08-16/`.

**Fix shape (three tasks).**

1. `tunnel_manager.py` — make `network_params` public (the watch needs the D-55 poll
   cadence); contain a raising probe/connect inside `ensure_connected()` as one spent
   attempt so the Table-19 bound holds for every failure mode (ERR_NGROK_334, no route,
   DNS). Docstring states the detection envelope honestly: pyngrok's `healthy()` latches
   its startup flags and probes only the LOCAL agent API, so the watch detects
   agent-process/local-API death; an upstream session blip is the ngrok agent's own
   built-in reconnect, invisible at this seam.
2. `tunnel_wiring.py` — `monitor_tunnel(tunnel)`: every `watchdog_poll_seconds`, probe
   `healthy()` via `to_thread`; on unhealthy run one bounded `ensure_connected()` via
   `to_thread`; print DOWN/RESTORED/EXHAUSTED evidence lines (stdout is retained round
   evidence); return after one exhausted repair. `run_with_tunnel` starts the task after
   `start()`+exchange block, cancels it in `finally` before `tunnel.stop()`
   (PeerRuntime's cancel+suppress shape). `sleep`/`to_thread`/`monitor` are injectable
   keyword-only seams (house DI style).
3. Tests — new raising-connect/raising-probe cases beside the existing reconnect suite;
   new `test_tunnel_wiring_monitor.py` (cadence, repair-and-continue, bounded give-up,
   probe-raise, cancel-on-exit, exhausted-before-body-ends); existing fakes gain the
   `network_params` attribute only.

**Non-goals.** No probe of the opponent's public URL (needs a probe timeout — a NEW
number, rule-1 blocker, raised and declined); no debounce threshold (same); no watchdog
changes (`tunnel_manager.py`'s docstring boundary stands); no Localtonet code path.
